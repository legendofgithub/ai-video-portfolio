# 丁博文 · AI 视频履历（作品集网站）

面向「AI 视频内容 / 评测实习生」岗位的单页作品集，全部素材来自 `漫剧` 文件夹（已转码为浏览器兼容格式）。

## 本地运行

```bash
node server.js        # 默认 http://localhost:8765
node server.js 9000   # 自定义端口
```

也可以用任意静态服务器（需支持 Range 请求，视频才能拖动进度条），例如：

```bash
npx serve .
python -m http.server 8765
```

直接双击 index.html（file:// 协议）也可以播放，但部分浏览器会限制拖动进度条。

## 素材说明

- `media/` 内所有 mp4 已统一转码为 H.264 + AAC（原素材中 HEVC/杜比视界编码在浏览器中兼容性差）。
- 分镜短片与画布实录本身是 H.264，直接拷贝使用。
- 角色三视图与神金小视频人设图取自素材文件夹 `人物/`、`神金小视频素材/`。
- `media/resume-dingbowen.docx` 为可下载简历（源文件：`丁博文简历（AI视频评测）.docx`）。

## 部署到 GitHub Pages

站点为纯静态页面，把本目录（含 `media/`）推送到仓库并开启 Pages 即可；注意仓库单文件 100MB 限制，`media/vamp-ep2.mp4` 约 44MB，可直接推送。若需进一步压缩，可用：

```bash
ffmpeg -i media/vamp-ep2.mp4 -c:v libx264 -crf 26 -preset medium -c:a aac -b:a 96k -movflags +faststart out.mp4
```
